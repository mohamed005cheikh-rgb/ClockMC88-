# L'Horloge Éternelle

## Description
Horloge analogique interactive avec effets de lumière naturelle et sons mécaniques.

## Fonctionnalités
- 🕐 Horloge en temps réel
- ☀️ Simulation jour/nuit avec ombres dynamiques
- 🔊 Sons de tic-tac et carillons
- ⏱️ Compteur de jours d'activité
- 📱 Design responsive

## Technologies
- HTML5 Canvas
- CSS3
- JavaScript vanilla
- Web Audio API
